# IT担当者の役割

IT担当者は、職員がアプリで正しい情報を見られるよう、**登録・権限・公開を管理する職員**です。IT系の専門職であることは前提にせず、管理画面で行う業務を担当します。

## 主な業務

1. **職員と権限の管理**：職員の利用権限を付与・変更・停止する。サービス管理者と、ニーズを編集できる職員を指定する。作業名は全職員が追加・編集でき、削除だけをIT担当者が行う。
2. **最初の情報登録**：Google Driveの資料から登録する内容を選び、利用者を確認してPDFを登録する。作業名と利用者ごとの評価は、既存資料を見ながら入力する。移行後はアプリの公開済み情報を現行版として扱う。
3. **変更内容の確認と公開**：通知・ステータス確認ページで、作業評価、PDF、六つのニーズなどの変更を確認し、承認または差し戻す。作業評価とスタッフ支援ポイントのPDFが食い違う場合は、注意表示を付けて公開し、PDFの記載を優先する。自分で変更した内容も公開前に確認する。
4. **利用終了と紛失への対応**：サービス管理者と同様に、利用終了日・最終サービス提供日を登録できる。端末紛失の連絡を受けた場合は、その端末のアプリ利用を停止する。保存期間を終えた記録の削除を申請する際は、サービス管理者の承認を受ける。
5. **担当の引き継ぎ**：通常はサービス管理者が後任のIT担当者を指定する。サービス管理者が病欠などで業務に就けない場合は、IT担当者が自身の後任を指定できる。

## 職員との分担

作業評価は担当職員が入力します。PDFはIT担当者またはサービス責任者が差し替えられます。サービス管理者はIT担当者の引き継ぎと記録削除の承認を担う、別のアプリ内権限です。IT担当者は、変更を公開する前の確認役です。

アプリの改修やサーバーの障害復旧が必要な場合は、開発・保守の担当者へ連絡します。

端末紛失時の停止・暗号化などの具体的な実装方法は、要件定義書で検討中です。
